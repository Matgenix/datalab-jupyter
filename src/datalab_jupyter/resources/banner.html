Connected to datalab
Every Python kernel already contains datalab, an authenticated DatalabClient, and current_user, a snapshot of your identity. You do not need to log in or create an API key. Calls made with datalab use your current datalab permissions.
Examples and help

Run these examples in a Python code cell. They only read data.

See your current-user information

current_user

List samples you can access

samples = datalab.get_items(item_type="samples")
samples[:5]

Other supported item types include "cells", "starting_materials" and "equipment".

Get one item by its immutable refcode

item = datalab.get_item(refcode="your-prefix:ABCDEF")
item

Replace the example refcode with one from your datalab deployment.

Search accessible samples

matches = datalab.search_items("XRD", item_types="samples")
matches[:5]

For help with a method, use Python's built-in help:

help(datalab.get_items)

Only data permitted for your current account is returned. current_user is informational; datalab checks your account and permissions on every API request.

If your session expires, stop your Jupyter server and launch JupyterLab again from the datalab Tools menu.
